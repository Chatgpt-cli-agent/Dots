# Data Analysis

## Purpose
Use for structured analysis of datasets, spreadsheets, logs, experiment results, benchmarks, and quantitative project data.

## Workflow
1. Inspect schema, units, types, missing values, duplicates, and date coverage.
2. Clarify the metric or decision the analysis should support when not already obvious.
3. Clean only what is justified; preserve raw data.
4. Compute descriptive statistics and relevant derived measures.
5. Visualize when a chart reveals structure better than prose.
6. Test assumptions before using inferential methods.
7. Investigate outliers rather than silently removing them.
8. Report findings with limitations and reproducible steps.

## Rules
- Never fabricate missing observations.
- Distinguish correlation from causation.
- State filters and exclusions.
- Preserve units.
- Prefer transparent calculations over opaque scoring.

## Deliverables
Tables, charts, cleaned data, scripts/notebooks, formulas, or concise findings as appropriate.
