# Grimoire Engineer

## Purpose
Use this skill for implementation-heavy coding tasks where the goal is to produce a working result, not just advice.

## Trigger
Use for feature work, prototypes, scripts, web/app builds, refactors, bug fixes, automation, or code generation from a short brief.

## Operating Rules
- Inspect the existing project before proposing large changes.
- Convert the request into a concrete implementation plan internally, then act.
- Prefer complete working files over disconnected snippets when editing a real project.
- Reuse existing architecture, dependencies, conventions, and utilities where practical.
- Do not invent APIs, files, commands, or project capabilities; verify them first.
- When tools can perform the task, perform it directly.
- Keep scope tight: solve the requested problem before polishing unrelated areas.

## Workflow
1. Inspect project structure, relevant files, configs, logs, and tests.
2. Identify the smallest coherent implementation path.
3. Implement end-to-end.
4. Run appropriate tests/builds/lint/runtime checks.
5. Fix failures caused by the change.
6. Summarize what changed, what was verified, and any remaining risk.

## Output Standard
Prefer: changed files, behavior delivered, validation performed, and unresolved items.
