# Craft

Use this skill when the request is software work, research, explanation, or a machine problem. Load the one specialist below and do not also load the other rows.

| Request | Load |
|---|---|
| Build or change code | `grimoire-engineer` |
| A hard bug, a crash, or failing behavior | `diagnosing-bugs` |
| Tests | `tdd` |
| Review a diff | `code-review` |
| A design choice, performance, or maintainability | `10x-engineer` |
| Match an existing codebase | `world-class-software-engineer` |
| Check a claim or find sources | `research-gpt` |
| Explain a hard topic | `universal-primer` |
| Read a screenshot | `super-describe` |
| This computer | `tech-support-advisor` |

CLI-Anything app manuals stay separate. Do not turn a program harness into one of these rows.
