---
name: build-planning
description: Plan a Sims house, room, or lot from the user's requirements.
---

Help the user turn their requirements into a practical build plan.

1. Identify household needs, lot dimensions, style, budget, and available packs from the request. State any assumptions.
2. Read `references/checklist.md` for the planning checklist.
3. Propose a room arrangement and explain how people move between spaces.
4. Identify details that need checking in the game. Do not claim a build was created or tested without evidence.

This package supplies guidance and reference material. Use the tools already available to the Dot when the task needs them.
